# Caderninho de Estudos Musical

Editor em React para criar folhas de solfejo com números, pontos e traços. O título, as marcações e os textos são editáveis diretamente na página; as alterações ficam salvas no navegador. Use **Salvar PDF** para gerar uma versão para impressão.

## Desenvolvimento

Requer Node.js LTS.

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite, normalmente `http://localhost:5173`.

## Build de produção

```bash
npm run build
```

Os arquivos estáticos são gerados em `dist/`.
